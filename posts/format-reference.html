Python

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

print(list(fibonacci(10)))

实用技巧

  • 段落之间空一行
  • 代码块和文字之间也空一行
  • 链接文字要有描述性，不要写"点这里"
  • 表格前后各空一行，保证兼容性
